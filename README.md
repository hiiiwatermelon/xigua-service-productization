# 西瓜 · 服务产品化

把专业服务中的知识与经验，转成客户愿意参与的互动产品入口。

`xigua-service-productization` 是一个 AI Skill。你提供业务资料，它帮助你设计自测、预诊断、模拟器等互动小产品，让客户在参与过程中理解自己的情况、感受你的专业能力，并找到进一步咨询或购买的理由。

## 适合什么时候使用

- 你有服务介绍、课程笔记或案例材料，希望把它们变成客户可以亲自体验的产品。
- 你经常重复回答相似问题，希望用一个互动入口帮助客户先理解自身需求。
- 你想做一个服务获客小工具，但还没确定应该做成什么形式。

可以提供 PDF、Word 文档、截图、链接、粘贴的笔记、服务文案、课程大纲、商业计划书或案例记录。材料不足时，Skill 会先询问必要信息。

## 它会帮你完成什么

1. **理解业务与客户。** 梳理你提供什么服务、客户面临什么问题，以及你希望客户下一步采取什么行动。
2. **提出至少三种不同的互动方案。** 说明客户如何参与、能得到什么结果、你能获得什么业务信号，以及各方案的风险与推荐评分。
3. **由你选择一个方向。** 先确定帮助客户理解自身情况的入口。
4. **生成完整的网站搭建提示词。** 包括互动机制、页面结构、输入字段、结果逻辑、转化动作和内容边界，可交给其他 AI 搭建工具或 Codex 使用。
5. **经你明确确认后搭建。** 制作可用的网站体验；是否能上线取决于使用环境中的托管和部署能力。

整个流程默认使用简体中文。Skill 不会在你选择方案、确认搭建之前直接开始制作网站。

## 可以设计哪些互动入口

| 形式 | 客户怎么参与 | 适合解决的问题 |
| --- | --- | --- |
| 自测 | 回答问题，获得画像、评分或风险提示 | 帮助客户识别自己的状态与盲点 |
| 预诊断 | 提供背景和问题，获得初步分类与建议 | 帮助客户在咨询前理清需求 |
| 模拟器 | 调整变量或选择情境，查看推演结果 | 让成本、风险与取舍更容易理解 |
| 问答知识库 | 提问或选择问题，获得情境化回答 | 回应常见困惑与决策疑问 |
| 案例拆解器 | 选择相似案例，查看分析并比较路径 | 帮助客户借助案例理解自身情况 |
| 方案匹配器 | 提供需求、限制与偏好，获得匹配建议 | 降低服务或方案的选择难度 |

具体推荐取决于你提供的材料，并非每种业务都适合所有形式。

## 安装到 Codex

下载本仓库 ZIP 并解压，将包含 `SKILL.md` 的文件夹命名为 `xigua-service-productization`，放入 Codex 的技能目录：

```text
~/.codex/skills/xigua-service-productization/
```

如果你配置了自定义 `CODEX_HOME`，则放入该目录下的 `skills/`。保留 `agents/` 和 `references/` 两个子目录，并确保没有多嵌套一层文件夹。

## 如何开始

安装后，在 Codex 对话中调用 Skill，并附上你的材料：

```text
使用 $xigua-service-productization。

这是我的服务介绍和案例材料，请帮我设计至少三种互动产品入口。
先比较各方案适合的原因、客户能得到的结果，以及我能获得的业务线索，
等我选定方向后再生成网站搭建提示词。
```

如果材料里没有这些信息，可以一起补充：

- 我提供什么服务。
- 我的目标客户是谁。
- 客户最常问什么、最难判断什么。
- 我希望客户体验后做什么，例如咨询、预约或加入课程。

## 使用边界

- 方案应依据你提供的材料，不虚构案例、数据或业务事实。
- 预诊断不能替代最终专业意见；模拟结果不能写成效果保证。
- 案例需注意隐私，个别案例不能用于承诺其他客户的结果。
- 互动产品入口旨在帮助客户理解需求和服务价值，不保证带来咨询或成交。
